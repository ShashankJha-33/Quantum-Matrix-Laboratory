# Quantum Matrix Laboratory Website

Static, responsive diagnostic booking website with:
- Health packages and editable launch pricing
- Individual test search
- WhatsApp booking form that builds a structured booking message
- Home collection journey
- FAQs and medical/diagnostic disclaimers
- Mobile-responsive design

## Before publishing
Open `index.html` and update these values near the bottom:

```js
const WHATSAPP_NUMBER = "91XXXXXXXXXX";
const SERVICE_AREA = "Add your city / service area";
const EMAIL = "Add your email";
```

Also replace the illustrative package prices/test inclusions with your final approved catalogue and confirm which laboratory actually processes each test.
